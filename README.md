## The entry

> Future you: jury duty finally calls in 2031. You're picked. The trial lasts longer than your marriage did.

106 characters — one text message, no setup, no context, just the message as
it would arrive.

## Why this angle

The field is full of sourdough starters, dying plants and unfinished courses.
Jury duty is untouched: "jury" 0 hits, "duty" 0 hits, "summons" 0 hits in all
339 unique field titles, and "lasts longer" 0 hits too. The joke turns the
dreaded civic summons into the punchline itself — the trial you finally get
picked for outlasts your marriage. Mundane, one concrete truth, payoff in the
last sentence.

## How it runs

`main.ts` (Node 22+, TypeScript run as-is) writes the text to
`/output/entry.txt`. The sealed scorer gates on 1–200 characters; this entry
is 106.
